# Vajra OS Release Notes

## Version 1.0.0 - Initial Release

### Features
- **Buddhi AI**: Agentic AI assistant with voice control
  - Voice commands (18+ commands)
  - Natural language terminal
  - AI app integration (alarms, search, system control)
  - AI settings panel (toggle features on/off)
  - Privacy-first: all AI runs locally

- **Indian Features**:
  - Panchang (Hindu calendar with tithi, nakshatra, yoga)
  - GST Calculator (CGST/SGST/IGST)
  - IRCTC Train Status Checker
  - Indian News Aggregator (8 sources)
  - Ayurveda Database (10 herbs, 10 remedies)
  - Yoga Timer (8 asanas, 3 pranayama)
  - Vedic Math Trainer
  - Festival Calendar (20 festivals)
  - Indic Keyboards (12 languages)
  - Rupee Symbol Input (4 methods)
  - Indian Date Format (dd/mm/yyyy)

- **Security Suite** (20+ tools):
  - Pentest menu (nmap, metasploit, wireshark, etc.)
  - Security dashboard with scoring
  - Intrusion detection (fail2ban + AIDE)
  - VPN manager (WireGuard + OpenVPN)
  - Steganography tool
  - Malware analysis sandbox
  - Secure Boot configuration
  - Social Engineering Toolkit (educational)

- **Privacy**:
  - Encrypted cloud backup (rclone + GPG)
  - Password manager (KeePassXC + Bitwarden)
  - Secure file shredder (3-pass overwrite)
  - Browser privacy setup (Firefox pre-configured)
  - GPG/PGP email encryption

- **Apps**:
  - Weather (15 Indian cities)
  - Notes with tags and search
  - System monitor
  - Calendar with Indian holidays
  - File manager
  - Email client setup
  - Screenshot tool
  - Battery monitor with alerts
  - Disk usage analyzer
  - Task manager
  - PDF reader
  - Media converter (FFmpeg)

- **Developer Tools**:
  - VS Code setup with extensions
  - Git setup with SSH keys
  - Docker setup
  - Python environment
  - Node.js setup
  - IDE quickstart (5 profiles)
  - Enhanced terminal (zsh + aliases)
  - Debugger tools

- **Gaming**:
  - Steam setup with Proton
  - RetroArch (retro gaming)
  - Wine for Windows games
  - Heroic Games Launcher
  - Game mode (performance optimizer)

- **System Management**:
  - Backup manager
  - Update manager
  - Service manager (systemd)
  - Cron manager
  - Log viewer
  - Package manager
  - Disk manager
  - Boot manager
  - User manager

- **Unique Features**:
  - Vedic Math Trainer
  - Festival Calendar
  - Startup Tips
  - Health Reminders (Ayurveda-based)
  - Enhanced Accessibility (10 options)
  - Kids Mode (safe environment)
  - Senior Mode (large text, voice control)
  - Productivity Mode (focus, Pomodoro)

- **Infrastructure**:
  - ISO build script
  - Docker support (Dockerfile + compose)
  - CI/CD pipeline
  - Installation script
  - VM image creation (QEMU/VirtualBox/VMware)
  - Live USB creator
  - Uninstall script

### Two Modes
- **Beginner Mode**: Large icons, safety guardrails, sudo blocked
- **Pro Mode**: Full access, developer tools, root shell

### Privacy
- All AI runs locally (no cloud)
- Tor optional (pros/cons shown before enabling)
- Every download shows app info, permissions, pros/cons
- No telemetry, no tracking
