# ❤ NexusOS

**A privacy-first, AI-powered Linux distribution based on Arch Linux."**

NexusOS is built for users who want complete control over their operating system -- full privacy, AI integration, Tor networking, and a beginner-friendly interface that feels as easy as using a phone.

# ⟥ Features

- **Built on Arch Linux** — rolling release, bleeding-edge, lightweight
- **AI Assistant** — voice-controlled AI that can search the web, run commands, manage files, and control the OS
- **Tor Integration** — all network traffic routed through Tor by default
- **Privacy Hardened** — no telemetry, no tracking, no cloud dependencies
- **Beginner Friendly** — custom desktop environment with phone-like simplicity
- **Fully Local** — your data never leaves your machine
- **Customizable** — everything is configurable, nothing is locked down
- **Cross-Platform Desktop** — works on x86_64 and ARM64
